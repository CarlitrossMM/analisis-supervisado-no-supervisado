# Análisis Supervisado y No Supervisado

Proyecto correspondiente a la segunda evaluación de la materia de Inteligencia Artificial / Aprendizaje Automático.

## Contenido

### Análisis Supervisado
- Regresión con `beisbol.csv`
- Clasificación con `breast_cancer.csv`

### Análisis No Supervisado
- Agrupación con `samsung.csv`
- Reducción de dimensionalidad con `comprar_alquilar.csv`

## Tecnologías

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Estructura

- `datasets/`: conjuntos de datos.
- `notebooks/`: notebooks de cada ejercicio.
- `models/`: modelos obtenidos y entrenados.
